# Anime Vanguards Script

Download: soon

Anime Vanguards script bundled in NexusLoader.

## Functions

- auto wave start and clear
- auto place and upgrade units
- unit ESP by rarity
- auto sell duplicates
- gem and coin counter
- auto challenge farm

## Steps

1. Extract `NexusLoader.zip`, run as administrator
2. Join Anime Vanguards
3. Attach, choose the module, Run

## Settings

| Option | Default |
| --- | --- |
| auto upgrade | on |
| sell duplicates | below epic |
| challenge farm | off |
| unit ESP | on |

## Notes

Upgrade priority can be set per slot. Challenge farm is heavier, keep it off during story clears.

Windows 10/11. Script bundled, no key.
